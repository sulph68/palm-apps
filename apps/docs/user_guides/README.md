# User guides

Short how-to guides for the apps in this suite. Features the built-in Palm apps already have are not repeated; only what is different or new.

| Guide | What it is |
|---|---|
| [Getting started: X-Master, Sec35](Getting_started.md) | Turn on the era plugin, set the password the suite shares |
| [Datebook35](Datebook35.md) | Calendar for any year, 1904-9999 |
| [ToDo35](ToDo35.md) | To Do list with time and repeat |
| [Address35](Address35.md) | Address book |
| [CryptoNote](CryptoNote.md) | Encrypted notes, also on the SD card |
| [BitWarden](Bitwarden.md) | Your Bitwarden / Vaultwarden vault, read-only |
| [CalDAV Sync](CalDAVSync.md) | Calendars and contacts from CalDAV, iCloud, Google |
| [EraNTP](EraNTP.md) | Set the clock from the network |
| [lazyFTP](LazyFTP.md) | FTP client |
| [Meshtastic](Meshtastic.md) | Chat over a Meshtastic node |
| [Bkp1](Bkp1.md) | Backup and restore to the SD card |
| [SASD](SASD.md) | SD card through the WiRSa |
| [McPhling](McPhling.md) | Swipe-up app launcher |
| [WiRSaControl](WiRSaControl.md) | Control WiRSa from the Palm |
| [WiRSa](WiRSa.md) | The WiRSa device and its menus |

Screenshots are from the emulator (Palm III, OS 4.1). Network apps need a WiRSa; without one they show their empty screens.
